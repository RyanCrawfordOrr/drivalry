# Drivalry — Good Company branding

The app’s shared Flutter theme, launcher icons, splash screens, sign-in mark, season cards and store artwork have been updated locally to the selected cream-and-coral **d** on aubergine.

## In this package

- **`brand/`** — editable SVG icon and transparent mark, plus the README banner. Use the cream transparent mark on a dark background.
- **`store/play/`** — Play icon, feature graphic and eight phone screenshots.
- **`store/appstore/`** — App Store icon, eight medium iPhone screenshots, optional large/older iPhone sets and one 13-inch iPad layout.
- **`store/social-preview-1280x640.png`** — social banner.
- **`store/README.md`** — dimensions, regeneration instructions and technical handoff.

Colours: aubergine `#392837`, cream `#F9ECDD`, coral `#F08566`. The app’s editable source remains in `C:\Drivalry\app`; the authoritative generated store files remain in `C:\Drivalry\store`.

## Before publishing

The screenshot artwork uses real Flutter widgets with example data, not device captures. The Drive map is a painted stand-in; phone hardware/status bars are simulated. Check screenshots, listing claims, actual platform appearance and permissions against the release build and replace images with genuine captures as needed. The iOS build and device appearance still need checking on a Mac and real devices. Android Auto screenshots, if declared, require separate head-unit captures. Nothing has been uploaded to either store.
